# 中国地图接入规范

游戏不得再使用手绘、无来源或从第三方示例仓库复制的中国轮廓。

正式公开版本的时代—文物地图必须：

- 直接使用自然资源部标准地图服务系统下载的、带审图号且未经编辑的标准地图；
- 在地图页面显著保留来源与审图号；
- 若为了交互而放大、裁切、标注、改色或叠加要素，则在公开前依规完成地图审核；
- 将文物标记与地图底图分层保存，保证审核底图可替换、审计和更新；
- 把“局部放大”作为底图视图能力，不伪造省界、海域或岛屿。

## 已核验的官方入口

- 标准地图服务系统：https://bzdt.tianditu.gov.cn/
- 系统明确提供“中国地图 1:4800万 64开 分省设色 有邻国 线划二”等中国全图；下载的标准地图须标注审图号。
- 系统同时明确：对地图内容作放大、缩小、裁切，或叠加图层后公开使用，须送自然资源主管部门审核。

## 产品发布闸门

在 `index.html` 的时代—文物地图上架前，维护者必须在这里补齐下列信息：

| 字段 | 必填内容 |
| --- | --- |
| `source_url` | 下载页或官方服务链接 |
| `approval_no` | 该具体底图显示的审图号 |
| `asset_sha256` | 原始、未改动文件的校验值 |
| `review_record` | 如做缩放、裁切或叠加文物标记，填写公开使用审核记录 |

当前开发入口已移除无来源的手绘中国地图，并保留到官方标准地图服务系统的查验入口；在获得带审图号、可用于该产品的底图前，不显示假地图。
