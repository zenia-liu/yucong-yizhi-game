# 器中城：玉琮王

一款以良渚文化玉琮王为入口的 3D 微缩考古箱庭游戏。玩家观察四面八幅神人兽面纹，展开带有地貌的器内四壁，进入水利、稻作、制玉、城台四个相互印证的空间，最后让八幅纹样归器。

## 当前方向：文物即世界

项目正在从“场景之间串联独立谜题”转向“在场景里调查证据”。每件文物共享以下循环：

1. 观察器物的形制、纹样和工艺痕迹。
2. 进入由器物结构展开的微缩世界。
3. 改变一个连续环境系统（例如水位、光线、材料或位置）。
4. 在环境变化中发现并记录证据，再让证据关系推动进度。

玉琮王的四个城域都已改为现场切片：水利面让玩家在西堤木闸泄水或蓄水，分别调查滩地木桩和舟道；稻作面让玩家先落下晒场遮棚，再让雨线抵达，观察谷物状态和上涨水道如何衔接装船；制玉面让玩家用侧光找出玉料隐裂，再校正对钻轴线；城台面让玩家扫开探方表土，依据器物位置校正纹样中轴。每面两条证据会在右下角研究簿中被记录并共同点亮纹样。全程不打开二维谜题面板。

`src/game/data.js` 中的 `ARTIFACTS` 是后续多文物内容的公共描述入口。目前预留了长信宫灯，用来验证“光线、气流、积灰”的同一套观察—调查—复原规则。

玉琮王结束页的“进入下一件文物：长信宫灯”已可直接进入第二个短篇。它用转动灯罩聚光、打开导烟口两个环境操作，分别调查案面光束与进入手臂空腔的烟迹。

## 运行

```bash
npm install
npm start
```

正式构建：

```bash
npm run build
```

打开终端显示的网址即可开始。游戏支持鼠标/触摸拖动器物、点击道路自动寻路，亦支持 WASD 或方向键移动；进度保存在浏览器本地。

## 完整流程

1. 旋转观察玉琮，向外拖开四个立面；器内微缩地貌随之显现，再分离上下射口。
2. 在水利面操作西堤木闸：低水位调查洲滩木桩与旧水痕，高水位验证舟道，借两条现场证据理解水位与运输的关系。
3. 在稻作面先为晒场落下遮棚，再观察雨线抵达后的谷物状态与上涨舟道；由两条现场证据理解收、晒、运为何属于同一场雨。
4. 在制玉面把看料灯转为侧照，观察玉料隐裂；根据裂隙校正导向架，再到对钻台确认两端孔道的相遇。
5. 在城台面扫开探方表土，观察器物位置；利用位置校正城台中轴，再在东侧拓片中确认同向神徽。
6. 复原八幅纹样，穿过中央圆孔，把六个结构投影拖回器物。

视觉采用“博物馆玉器 + 建筑模型式微缩箱庭”：保留精确阴影、玉质层次和可放大观察的场景细节，不再使用水彩滤镜。四城的机关、道路、地貌和地标均不同；角色由网格寻路约束，只能走道路与已开启的桥门，不能穿屋或涉水。所有三维场景和音效由程序生成，不依赖在线服务。

## 史实与艺术重构

器物按反山 M12:98 的关键资料重做：通高约 8.9 厘米、射径约 17.1—17.6 厘米、内圆外方、中央对钻圆孔；四面直槽内上下各一幅完整神人兽面纹，共八幅。纹样表现羽冠、神人面、兽面重圈眼、鼻梁与肢爪，并以浮雕和阴线两个层级区分。良渚古城的水利系统、稻作、专业制玉和反山高等级墓地构成四个城域调查的史实依据。

“结构投影”、器中城市和具体机关均为游戏化艺术重构，不表示真实玉琮可以拆分，也不把箱庭地图冒充遗址复原图。事实边界参照[联合国教科文组织良渚古城遗址说明](https://whc.unesco.org/en/list/1592/)与[上海博物馆良渚神徽研究资料](https://www.shanghaimuseum.net/mu/asset1/20150521/a66ba675-1613-4536-b8ca-648aa7df6fcb.pdf)。水位、晒场、看料侧光、对钻和探方位置均以这些研究主题为灵感；它们的具体可操作形式属于艺术重构。河流视觉借鉴实时水面常见的流向细纹、分层深浅色与破碎岸边泡沫，而非把白色图形当作浪花贴在水面上。
