# 器中城：玉琮王

一款以良渚文化玉琮王为入口的 3D 微缩考古箱庭解谜游戏。玩家观察四面八幅神人兽面纹，展开带有地貌的器内四壁，进入水利、稻作、制玉、城台四个相互印证的空间，最后让八幅纹样归器。

## 运行

```bash
npm install
npm start
```

正式构建：

```bash
npm run build
```

打开终端显示的网址即可开始。游戏支持鼠标/触摸拖动器物、点击道路自动寻路，亦支持 WASD 或方向键移动；进度保存在浏览器本地。

## 完整流程

1. 旋转观察玉琮，向外拖开四个立面；器内微缩地貌随之显现，再分离上下射口。
2. 在水利面先复原一张有唯一解的 5×5 无漏口闸渠网，放下北桥抵达洲岛；再按数字、连通与不交叉约束为十五座洲岛架桥，南桥落下后才可沿南堤离城。
3. 在稻作面根据先后与相邻线索安排六道工序，闸门打开后沿田间横堤抵达三条船；调度完成后由南侧晒场道路离开。
4. 在制玉面布置看料灯阵，让玉面全数受光；灯门开启后经玉坊廊道抵达对钻台，再沿东侧工坊路离开。
5. 在城台面根据行列连续数复原 10×10 夯土探方，打开城台中门后抵达微雕台；最后沿右侧台阶到达归器门。
6. 复原八幅纹样，穿过中央圆孔，把六个结构投影拖回器物。

视觉采用“博物馆玉器 + 建筑模型式微缩箱庭”：保留精确阴影、玉质层次和可放大观察的场景细节，不再使用水彩滤镜。四城的机关、道路、地貌和地标均不同；角色由网格寻路约束，只能走道路与已开启的桥门，不能穿屋或涉水。所有三维场景和音效由程序生成，不依赖在线服务。

## 史实与艺术重构

器物按反山 M12:98 的关键资料重做：通高约 8.9 厘米、射径约 17.1—17.6 厘米、内圆外方、中央对钻圆孔；四面直槽内上下各一幅完整神人兽面纹，共八幅。纹样表现羽冠、神人面、兽面重圈眼、鼻梁与肢爪，并以浮雕和阴线两个层级区分。良渚古城的水利系统、稻作、专业制玉和反山高等级墓地构成四个谜题面的史实依据。

“结构投影”、器中城市和具体机关均为游戏化艺术重构，不表示真实玉琮可以拆分，也不把箱庭地图冒充遗址复原图。事实边界参照[联合国教科文组织良渚古城遗址说明](https://whc.unesco.org/en/list/1592/)与[上海博物馆良渚神徽研究资料](https://www.shanghaimuseum.net/mu/asset1/20150521/a66ba675-1613-4536-b8ca-648aa7df6fcb.pdf)。水闸直接采用 Simon Tatham《Net》的公开 5×5 题面 `5x5:1319827eb3e918b6ae4b1a326`；洲岛题采用 [Nikoli 桥をかけろ](https://www.nikoli.co.jp/en/puzzles/hashiwokakero/) 的数字、双桥、不交叉和全连通规则；看料灯阵采用 [Nikoli / Light Up](https://www.chiark.greenend.org.uk/~sgtatham/puzzles/doc/lightup.html) 的完整照明规则；神徽九宫采用 [Fifteen 滑块谜题](https://www.chiark.greenend.org.uk/~sgtatham/puzzles/doc/fifteen.html) 的相邻滑块规则；三芯校孔采用小型推箱子式的“只能推不能拉”空间约束。河流视觉借鉴实时水面常见的流向细纹、分层深浅色与破碎岸边泡沫，而非把白色图形当作浪花贴在水面上。
